Como Publicar este Dashboard Gratuitamente na Nuvem

Para gerar um link público (HTTPS) para acessar este Dashboard de qualquer celular, tablet ou computador do Senac sem precisar de servidor pago, escolha uma das opções gratuitas abaixo:

1

Opção A: Vercel (Recomendado - 1 Minuto)

1. Crie uma conta gratuita em vercel.com.

2. Arraste a pasta deste projeto saul_elkind_web_dashboard para a tela da Vercel.

3. Clique em Deploy. Você receberá um link como https://saul-elkind-senac.vercel.app.

2

Opção B: Netlify Drop (Sem Instalação)

1. Acesse app.netlify.com/drop.

2. Arraste a pasta do projeto para a caixa de upload.

3. Seu site estará no ar instantaneamente com link público!

3

Opção C: GitHub Pages

1. Suba este projeto para um repositório público no GitHub.

2. Vá nas configurações do repositório em Pages e selecione a branch main.

3. Acesse em https://seu-usuario.github.io/saul-elkind-dashboard.
